# 💼 Job Salary Predictor

A machine learning web application that predicts job salaries based on 
various professional factors.

## 🚀 Features
- Predicts salary based on job title, experience, skills, and more
- Built with a trained ML model on 250,000+ data points
- Clean and responsive web interface
- Real-time predictions

## 🛠️ Tech Stack
- **Python** — Core programming language
- **Scikit-learn** — Machine learning model
- **Flask** — Web framework
- **Pandas & NumPy** — Data processing
- **HTML/CSS** — Frontend interface

## 📊 Input Features
- Job Title
- Years of Experience
- Education Level
- Skills Count
- Industry
- Company Size
- Location
- Remote Work
- Certifications

## ⚙️ How to Run Locally
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open: `http://127.0.0.1:5000`
